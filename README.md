\# FitTrack - Organizador de Treinos



\## Sobre o projeto



O FitTrack é um aplicativo desenvolvido com React Native e Expo para organizar e acompanhar treinos físicos.



\## Objetivo



Facilitar a organização da rotina de exercícios por meio de uma interface simples e moderna.



\## Tecnologias utilizadas



\- React Native

\- Expo

\- JavaScript



\## Telas do aplicativo



\- Home: tela inicial.

\- Treinos: organização dos exercícios.

\- Perfil: informações do usuário.



\## Como executar



1\. Instale as dependências:



npm install



2\. Inicie o projeto:



npx expo start
